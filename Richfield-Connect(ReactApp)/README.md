## Description

Richfield Connect is a React Single Page Application designed for students to:

- Register profiles
- View profile information
- Create posts
- Like posts
- Delete posts
- Store data using localStorage

## Running app from desktop
1. Opening VS code and terminal in vs code
2. In terminal, locate file folder(such as C:/downloads/richfield-connect)
3. Type npm install
4. Then type npm install react-router-dom
5. npm run dev
6. Local host network should appear, and run local host in browser

## Running app from mobile
1. Do step 1-6 from running app from desktop
2. Connect destop computer and mobile phone/tablet to same internet access network
3. Type npx vite --host to expose local host netweork over shared network medium
4. On the mobile computer, type the IP expose network address that appears below the localhost that appeared in step 6 in the destop.
